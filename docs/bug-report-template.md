# Bug report template

Used in Jira (space TUR) as the default description of the Bug work type.

Workflow: To Do -> In Progress -> Testing -> Done.
A fix goes to Testing first and is closed only after it has been verified.

## Summary

One line, area first: `[Area] What is wrong`
Example: `[CI] Daily pipeline fails: dev server is missing SUPABASE_URL`
